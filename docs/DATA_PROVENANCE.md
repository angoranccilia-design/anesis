# Data provenance

Every important number has: **source · timestamp · formula · assumptions · data quality · confidence · status**. The console's evidence inspector shows all of them on click; the report prints them; Ask Anesis cites the record ids.

## Status vocabulary

VERIFIED (read from a system of record or a live connector) · SIMULATED (generated by the simulated-property model) · MODELLED (computed by a declared formula) · BENCHMARK (placeholder reference until a documented source replaces it) · EXPERIMENTAL (hypothesis under test). In this environment no property observation is VERIFIED; live weather, holidays and exchange-rate signals are.

## Example

```
OBS-003  adr = 192 GBP/night
  source        SRC-SIM-PMS (simulated PMS export)
  timestamp     run time
  transformation raw (simulated)
  status        SIMULATED · confidence 0.95
C-001  Mobile booking conversion below benchmark
  formula       sessions.mobile × (benchmark − conv.mobile) × booking_value_avg  [low p50, high p75]
  evidence      OBS-015, OBS-017, OBS-016, OBS-014, OBS-028
  assumptions   benchmark placeholders; average booking value; blended attainment
  status        MODELLED · confidence 0.6
```

## Freshness and quality

`DataQuality { completeness, reliability, ageHours, expectedFreshness, stale, note }`. A source older than its class tolerance is **STALE DATA** and its note says so. Quality factor = completeness × reliability × (0.5 if stale). The factor is applied to the confidence of every intervention whose evidence rests on that source; the reduction is written into the intervention's `confidenceBasis` and listed in the run's `dataQualityNotes` ("decision confidence reduced"). Old data never appears as current: the timestamp and the age are part of the record.

## How uncertainty reaches the decision

- Intervention confidence × quality factor → expected value → risk-adjusted score → funding, blocking, VOI.
- Signal reliability R → relevance E = R × C × M → verdict.
- Measurement: the 90 % interval and the placebo rank decide ESTABLISHED / PROVISIONAL / INCONCLUSIVE.
- Calibration: shrinkage n/(n+3); INCONCLUSIVE never calibrates.

## What the language layer may do

Restate the facts of a structured answer in the speaker's language. It receives only those facts; it may not add a number, a cause, a forecast, a probability, a price or a source. Without a key it is off and the console says so.
